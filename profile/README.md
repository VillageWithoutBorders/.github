# Village Without Borders

A free mutual aid app that helps neighbors find each other, share skills, and take care of one another.

It started in Northwest Georgia and the Chattanooga Valley. It is built so any town can grow a village of its own.

- **Use the app:** https://app.villagewithoutborders.org
- **See the code:** [village-without-borders](https://github.com/VillageWithoutBorders/village-without-borders)
- **Start a village in your town:** see the README in the code
- **Help out:** read [Helping with VWB](https://github.com/VillageWithoutBorders/village-without-borders/blob/main/CONTRIBUTING.md) and [How We Treat Each Other](https://github.com/VillageWithoutBorders/village-without-borders/blob/main/CODE_OF_CONDUCT.md)
